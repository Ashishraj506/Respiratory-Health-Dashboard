# 📊 Excel Dashboard: Healthcare Facility Analysis

This repository contains an interactive Excel Dashboard that provides insights into healthcare facilities across various counties. The dashboard uses pivot tables and charts for visual analysis of key metrics like emergency visits, bed sizes, and facility designations.

## 📁 File

- **Excel Dashboard.xlsx** – The main Excel file containing the dashboard, pivot tables, and source data.

## 🔍 Features

- Pivot table analysis by:
  - Rehabilitation Center
  - County Name
  - Hospital Ownership
  - Urban/Rural Designation
- Charts displaying:
  - Emergency Department (ED) Visits
  - ED Station Counts
  - Licensed Bed Size by Category
- Filterable fields including:
  - Primary Care Shortage Area
  - Mental Health Shortage Area
  - Teaching Designation
- Geographic context via Latitude and Longitude columns

## 🖥 How to Use

1. Download or clone this repository.
2. Open `Excel Dashboard.xlsx` using Microsoft Excel (Office 365 recommended).
3. Interact with slicers and filters to explore different data views.
